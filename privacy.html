Kebijakan Privasi Atap

Berlaku sejak 19 November 2026

Atap adalah aplikasi kasir dan stok barang untuk Android. Halaman ini menjelaskan data apa yang dipakai Atap dan ke mana data itu pergi.

1. Data yang disimpan di HP

Data barang, stok, penjualan, pelanggan dan piutang, kas, serta akun pegawai (nama, peran, dan PIN dalam bentuk hash) disimpan di penyimpanan aplikasi pada HP toko. Data ini tidak dikirim ke pengembang Atap. Atap tidak punya server.

2. Akun Google (opsional)

Pemilik toko dapat masuk atau mendaftar dengan akun Google. Atap meminta izin berikut:

  • Alamat email, nama, dan foto profil, untuk mengenali pemilik toko di HP itu dan sebagai cara masuk bila lupa PIN.
  • Google Drive, hanya file yang dibuat Atap (drive.file), untuk menyimpan dan membaca file cadangan toko. Atap tidak bisa melihat file lain di Drive.

Data akun Google hanya disimpan di HP toko dan tidak dikirim ke pihak lain.

3. Cadangan di Google Drive

Bila diaktifkan, Atap menyimpan file cadangan di folder "Atap Backup" pada Google Drive milik pemilik. File itu dikunci dengan kata sandi cadangan yang dibuat pemilik, sehingga isinya tidak bisa dibaca tanpa kata sandi tersebut, termasuk oleh Google dan pengembang Atap. Pemilik dapat memutus akses Atap kapan saja di Atap atau di pengaturan akun Google, dan dapat menghapus file cadangan dari Drive.

4. Kamera, Bluetooth, dan berbagi file

Kamera dipakai untuk memindai kode batang di HP. Gambar tidak disimpan dan tidak dikirim. Bluetooth dipakai untuk printer struk. Struk, laporan PDF/Excel, dan laporan masalah hanya dibagikan bila pengguna sendiri memilih aplikasi tujuan, misalnya WhatsApp.

5. Yang tidak dilakukan Atap

  • Tidak menampilkan iklan.
  • Tidak memakai analitik atau pelacakan.
  • Tidak menjual atau membagikan data kepada pihak lain.

6. Menghapus data

Menghapus aplikasi menghapus seluruh data di HP. File cadangan di Google Drive tetap ada sampai pemilik menghapusnya sendiri.
